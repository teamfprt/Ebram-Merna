# موقع خطوبة محمود & آية

## هيكل الملفات
```
engagement-site/
├── index.html          كل نصوص وهيكل الصفحة
├── css/
│   └── style.css       الألوان والخطوط والتصميم وحركة البتلات
├── js/
│   └── main.js         الإعدادات (CONFIG) + التقويم + الموسيقى + الخريطة
└── assets/             حط ملفاتك هنا (مش موجودة حاليًا، لازم تضيفها):
    ├── song.mp3         أغنية الخطوبة
    ├── couple.jpg        صورة العروسين
    └── hall.jpg          صورة القاعة
```

## أهم حاجات تقدر تعدلها بسرعة

1. **الأسماء والتواريخ والنصوص** → داخل `index.html` مباشرة (كله نص عادي بالعربي).
2. **رابط خرائط جوجل للقاعة** → في `js/main.js` أول سطر بعد `CONFIG`، غيّر قيمة
   `GOOGLE_MAPS_URL`.
3. **موعد المناسبة (يستخدم في التقويم وزر "أضف لتقويمك")** → في `js/main.js`
   داخل `CONFIG.EVENT` (السنة، الشهر، اليوم، الساعة).
4. **الألوان** → في أول `css/style.css` تحت `:root`، كل الألوان متسمّاة
   (`--color-rose`, `--color-gold`...) وتقدر تغيّرها من مكان واحد.
5. **عدد بتلات الورد المتساقطة** → `CONFIG.PETALS_COUNT` في `main.js`.

## طريقة التجربة محليًا
افتح `index.html` مباشرة في المتصفح. لو حابب تشغّله بسيرفر بسيط (مستحسن
عشان الأغنية والصور تشتغل بدون مشاكل CORS في بعض المتصفحات):
```
cd engagement-site
python3 -m http.server 8080
```
وبعدين افتح `http://localhost:8080` في المتصفح.

## ملاحظة عن التوافق مع الجوال
- الموقع Responsive بالكامل ومتوافق مع RTL.
- الـ Visualizer (المؤثر البصري للموسيقى) هيشتغل بعد أول تفاعل من المستخدم
  (ضغطة زر "ابدأ") لأن أغلب المتصفحات بتمنع تشغيل الصوت التلقائي بدون تفاعل.
